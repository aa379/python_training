# Python Daily Training

這是我為了精進 Python 程式語言，所建立的每日練習與學習紀錄。
這份專案記錄了我逐步熟悉 Python 語法的過程，並作為我未來開發完整軟體系統的技術基石。

## 學習目標 (Learning Objectives)

* **鍛鍊解題邏輯**：透過實作 CPE (大學程式能力檢定)、LeetCode 等各類程式平台的精選題目，維持程式手感，並強化問題解決能力。
* **深化學理基礎**：在解題過程中，將理論與實務結合，深入熟悉**資料結構**與**演算法**的實際應用，並加強**排列組合**、**數論**等數學概念在程式中的實作。
* **長期專案準備**：透過每天一點一滴的累積，為未來獨立開發大型軟體系統打下堅實的技術基礎。

## 資料夾結構 (Repository Structure)

本專案以日期作為資料夾分類，主要收錄每日解題程式碼與思考筆記。

## 未來展望 (Roadmap)

持續刷題維持手感，把 Python 的基礎與語法打穩。

擴展技能樹，學習機器學習 (Machine Learning) 與自然語言處理 (NLP) 等核心領域。
